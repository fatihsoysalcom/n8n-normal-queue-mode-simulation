# n8n Normal Queue Mode Simulation

This example simulates n8n's 'Normal' (synchronous) and 'Queue' (asynchronous with workers) operating modes. It demonstrates how queue mode can handle a peak load of 19 jobs more efficiently by processing tasks concurrently. The simulation highlights the performance benefits of asynchronous processing for workflow automation.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
